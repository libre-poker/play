# The dynasty

Retired champions, kept whole. Each file is the exact strategy table that
held the ladder's summit, named by generation, abstraction, and training
budget. The ladder's history is replayable: any rated match ever played
against a champion can be re-graded against the very table that sat there.

- **champion-1-ehs1-300m.json** — the founding champion: first-generation
  equity abstraction, 300M CFR iterations. Reigned until 2026-08-17.
  Career: essentially unexploitable by LBR (−0.7 bb/100 lower bound),
  never beaten by a human over a settled sample, dethroned +1.41 bb/100
  over 40,000 hands by its EHS2 successor. Died undefeated by people.
